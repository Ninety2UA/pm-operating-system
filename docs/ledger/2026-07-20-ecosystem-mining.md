# Ecosystem Mining Ledger — 2026-07-20

Dated adopt/adapt/skip ledger for the six-repo ecosystem mining pass
(initiative: Anthropic Refresh and Ecosystem Mining). This file is the
authoritative record the adoption matrix and both watchers reconcile
against; consistency ordering: **ledger > registry seed > rebuildable
live state**.

## Method and trust boundary

- **Fetch-only profile:** HTTPS reads via WebFetch/scrape only — no `git
  clone`, no local checkout, no execution of anything fetched. Analysis at
  a pinned SHA per repo; per-fetch size caps; ≤3 GitHub API calls per repo.
- **Profile enforcement this run:** six read-only research subagents ran
  under instruction-level constraints (no Bash, no clone, no file writes —
  findings returned as text); the orchestrator verified returns and wrote
  this artifact. Hard per-invocation tool stripping is not available for
  subagents on this host — the scheduled watchers get the hard profile via
  the restricted-profile work (U9). Recorded honestly rather than claimed.
- **Defang-on-write:** every verbatim upstream string below passed through
  `core/scripts/defang.py` before landing here (markdown links/images/HTML
  neutralized to inert code spans, schemes defused, control characters
  stripped). Quotes are clearly marked; everything else is authored prose.
- **Authoring guideline:** rationales are respectful, fit-to-this-repo
  technical assessments written as if the named maintainer will read them.
  A skip or adapt verdict states why a pattern doesn't fit *here* — never
  a quality judgment of the source. "Import nothing" is a valid outcome.
- **Sensitive surfaces:** candidates whose adoption would touch hooks,
  `settings*`, allowed-tools, `.gitignore`, guard/safety code, MCP
  handlers, `setup.sh`, or the enforcement code itself
  (`build_adapters.py`, `validate.py`, `core/scripts/tests/`) carry the
  `heightened-review` tag: they cannot be adopted from this summary alone —
  the owner reads the real upstream and the actual diff first.
- **Row contract (machine-parsed):** candidate rows match
  `| <REPO>-<NN> |`; verdict ∈ {adopt, adapt, skip, already-via-plugin,
  not-found}; `Adopted-in` holds the implementing commit once a wave lands
  (`—` until then). Adopt/adapt rows missing an implementing commit at
  close are flagged by the validator.
